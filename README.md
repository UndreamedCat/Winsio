# Winsio
## About the Project
**Winsio** is a project that allows you to use a Casio-like calculator in Windows/Linux.

+ GUI Based on `PyQt6-Fluent-Widgets`
+ A Normal Calculator
+ Solving Formulas
+ Drawing Graphs from Function
+ Finding the Extreme Point of a Function
+ Customize Python Program
+ AI
